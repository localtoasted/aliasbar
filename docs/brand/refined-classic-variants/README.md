# Refined Classic treatments

All ten options keep the selected Refined Classic symbol: a greater than mark followed by two horizontal bars. Only the material, depth, and color treatment changes.

| File | Treatment |
| --- | --- |
| `01-elevated.png` | Elevated violet with raised white pieces |
| `02-machined.png` | Brushed violet metal with silver pieces |
| `03-soft-touch.png` | Soft touch violet with warm white pieces |
| `04-enamel.png` | Gloss enamel with a fine metal edge |
| `05-paper.png` | Textured paper and board |
| `06-flat.png` | Crisp flat artwork for small sizes |
| `07-emboss.png` | Blind embossed dark leather |
| `08-porcelain.png` | Glazed violet ceramic |
| `09-resin.png` | Translucent violet resin |
| `10-light.png` | Warm light base with a recessed violet mark |

The matching `-source.png` files preserve the generated originals. The files without that suffix have transparent backgrounds and are ready for review or export.

Machined Metal is the selected app icon and title treatment. Flat Precision remains available as the small-size fallback source.
